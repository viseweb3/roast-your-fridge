One line that roasts a fridge. That's the whole entry.

> My fridge wears magnets holding takeout menus from restaurants that shut down in 2021 — it's not an appliance, it's a graveyard with a light inside.

## Run it

```sh
node main.ts
```

It prints exactly one line (148 characters) and nothing else — deterministic,
no network, no randomness.

## Why this line

- **Really about a fridge:** magnets on the door, takeout menus, the light
  inside — nothing here could be about a phone.
- **Specific detail worth mocking:** not "my fridge is old", but the
  archaeology stuck to its door — menus for restaurants that closed in 2021.
- **The twist:** it stops being an appliance and becomes a graveyard — one
  that still has its light on.
- **Reads well out loud:** one breath, setup then punch, with the em-dash
  doing the turn.
